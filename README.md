# AdServe

AdServe is a production-minded miniature advertising platform built as part of a long-term backend and distributed-systems learning program.

The project focuses on engineering judgment rather than feature count.

## Goals

Develop depth in:

- Go
- backend/API design
- PostgreSQL
- Redis
- Kafka
- distributed systems
- online ad serving
- measurement
- attribution and identity
- budget pacing
- Docker and Kubernetes
- observability and reliability
- system design
- technical ownership
